# Keyboard shortcuts

On Windows, use Ctrl where a Mac uses Cmd. The one exception is help, which is F1 on Windows.

## Playback

These work anywhere in the editor, except while you type in a box.

| Key | What it does |
| --- | --- |
| Space | Play or pause |
| K | Pause |
| L | Play forwards. Press again to play faster. |
| J | Play backwards. Press again to play faster. |
| Left arrow | Back one frame |
| Right arrow | Forward one frame |
| Shift+Left arrow | Back one second |
| Shift+Right arrow | Forward one second |

## Editing

| Key | What it does |
| --- | --- |
| Cmd+Z | Undo |
| Shift+Cmd+Z | Redo |
| Click a word | Jump there and select it |
| Shift-click a word | Select every word from the selected one to it |
| Delete or Backspace | Cut the selected words, or restore them if they're all cut |
| Esc | Clear the selection |
| Double-click a word | Fix a misheard word |
| Enter | Save the fixed word |
| Esc, while fixing a word | Leave the word as it was |

## Around the app

| Key | What it does |
| --- | --- |
| Enter, in Ask for a change | Send the request |
| Left and Right arrows, on the tool tabs | Move between Edit, Look, Publish and Export |
| Arrow keys, on a panel's edge | Make the panel bigger or smaller |
| Home and End, on a panel's edge | Make the panel its smallest or largest |
| Arrow keys, on the thumbnail text or its corner | Move or resize the text. Add Shift to move five times as far. |
| Enter, while renaming a project | Save the name |
| Esc, while renaming a project | Keep the old name |
| Up and Down arrows, in a project's menu | Move through the menu. Esc closes it. |

## Help

| Key | What it does |
| --- | --- |
| Cmd+? on a Mac, F1 on Windows | Open ClipCat Help |
| Cmd+F, in the Help window | Search the help |
