ClipCat 0.1.3 fixes the AI editor on the Claude API, lets a project hold several music tracks, adds Play from the beginning, and makes every change one undo step. If you have 0.1.2, ClipCat updates itself.

Once 0.1.3 saves a project, 0.1.2 can't open it, because a project's music is now a list of tracks.

## AI editor

- Claude API runs work again. Every Suggest an edit run was refused with a 400. (#64)
- An old failure no longer stays on screen after a newer run worked. This is why OpenAI and OpenRouter looked broken when they had finished. (#64)
- A failure names the job, the AI and the model, on screen, in the log and in the project's history. Before, every failure was logged as Claude. A finished run says what it came to. (#64)
- OpenAI and OpenRouter ask once more when the connection drops mid-request, and the error says why it dropped. (#64)
- OpenRouter lists only models that read images and use tools. A saved model that's no longer listed has to be picked again, and runs don't use it meanwhile. (#64)

## Music

- A project can have several music tracks. One plays under the whole video, and others go on the words you pick, by hand or by the AI editor. Old projects open with their one track. (#64)
- Exports no longer hang on music. (#64)

## Editing

- Play from the beginning: a transport button, Enter, and a Playback menu item jump to the first kept moment and play. Enter still does its own job in boxes, menus and dialogs. (#65)
- Every change is one undo step: word fixes, captions, speed, shape, framing, chapters, the write-up, the thumbnail, music, and removing media or music. One slider drag is one step. (#65)
- Exported captions are the same size as in the preview, so they export bigger than before. Boxed word-by-word captions are one clean box. (#64)
- Blurred bars are smooth in the preview, and titles ending in a full stop no longer give `..mp4`. (#64)

## Settings and look

- Settings has one AI models page holding the AI editor and the coding agents. The coding agents part keeps Things to ask and a link to the full guide. (#64)
- The tool tabs have their tape-strip look back, and the transcript's action row uses arrows instead of a scrollbar. (#64)
- Help search puts the exact phrase first. (#64)

## Imports

- Videos dragged in from Photos are copied into the project, because macOS deletes the file Photos hands over. Older projects with such a video export from the preview copy. (#64)

## Builds

- Apple Silicon builds run on macOS 15, because GitHub retires its macOS 14 machines on November 2. (#64)
