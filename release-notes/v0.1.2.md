ClipCat 0.1.2 adds an AI editor page in Settings with OpenAI and OpenRouter, help pages, a fuller menu bar, a reworked Settings window, more coding agents, and more control over thumbnails, captions and the transcript. If you have 0.1.1, ClipCat updates itself.

## Editing

- The preview has ClipCat's own playback controls. (#45)
- Retype a word the transcript got wrong. (#50)
- A switch hides cuts from the transcript and the strip, so you can read what's left. (#51)
- A wide video can fill the sides of a vertical clip with a blurred copy of itself. (#52)
- Rename projects, open a project menu, keep the tool tab you were on, pick caption colours, and see the history of edits you accepted or turned down. (#49)

## Thumbnails

- The thumbnail takes the video's shape, and you can move and resize its text. (#47)
- The exported video carries the thumbnail as its cover art. (#46)
- Thumbnail text has eight more colours, picked from a menu. (#54, #56)

## Transcription

- Transcription settings: pick the language and the speech model for new projects. The list of languages is published in the help pages. (#48)

## Help and menus

- Help pages for every part of the app, in a Help window and a Help menu, and on the site at /docs. (#53, #55)
- The menu bar has File, Edit, View and Playback menus. (#58)

## AI editor

- Settings has an AI editor page, first in the list. Pick the AI that suggests edits, its model, and your keys. Claude Code and Codex run on your plan, with the same install and update line as on Coding agents. (#63)
- Bring your own OpenAI or OpenRouter key, as well as a Claude API key. Each key is checked once, then kept encrypted on your computer. The model list comes from that key. (#63)
- The Edit tab keeps the **Use** picker and shows which model runs. **AI settings** opens the page, or **Set up** when the AI can't run yet. (#63)

## Settings and coding agents

- Settings is split into pages: Coding agents, Transcription, Updates and Troubleshooting. The list on the left says where each one stands. Check for Updates opens it on Updates. (#60)
- Connect ClipCat to Cursor, VS Code, Windsurf, LM Studio and Gemini CLI, as well as Claude Code, Codex and the Claude desktop app. Gemini CLI installs and updates from Settings. For any other MCP app, Settings shows the setup to copy. (#59)

## Builds

- Vercel skips preview builds on agent branches and on changes that don't touch the site. (#57)
- A Mac build stops as soon as signing fails, and the staple check is retried until Apple's ticket shows up. (#62)
